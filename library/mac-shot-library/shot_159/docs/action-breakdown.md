A clean context-to-assistance surface where a communication thread becomes a structured AI summary and action panel. The shot should make the source context readable first, then let the assistant output gain priority without feeling like a hard scene swap.

## Motion Language

1. contextSurfaceReveal: the email or source thread stage enters as the semantic anchor.
2. sourceContextDock: the source panel firms up and gives the assistant something real to act on.
3. assistChipResolve: contextual action chips appear near the content to imply intent selection.
4. summaryCardLift: the recommendation panel rises into focus with the key output.
5. insightRowsCascade: recommendation rows and follow-up items resolve one by one.
6. explanationHold: the whole assist state settles and holds for legibility.
