## Visual Structure

A clean metrics dashboard composed of high-contrast number cards, narrow trend modules, and supporting summary rows. The composition emphasizes KPI readability first, with enough motion to feel alive without losing the operational-dashboard tone.

## Motion Structure

1. Dashboard frame glides in on a light blue stage.
2. Top metric cards reveal with a left-to-right sweep.
3. Trend charts draw in beneath the metric row.
4. Supporting summary rows and comparison chips settle into place.
5. The whole dashboard holds with a restrained horizontal focus drift.

## Reuse Value

Useful for pricing insight, performance metrics, risk dashboards, KPI reports, and data-heavy product promos.

## Risks

- Too many numbers can feel noisy if labels are not short.
- Trend cards must remain semantically tied to the metrics, not decorative.
- Wide dashboards can feel static if the reveal timing is too flat.
