## Visual Structure

A large horizontal prompt bar on a bright macro UI surface, with inline icons and a focused typing zone. The composition should feel interaction-first and readable from the first glance.

## Motion Language

1. commandBarReveal: the main prompt field establishes itself at center stage.
2. caretPulse: the typing position gets a restrained pulse to imply active input.
3. iconSnapSequence: inline tool icons appear in a controlled left-to-right rhythm.
4. macroSurfaceDrift: the whole surface gets a slow camera-style drift for depth.
5. inputHold: the final search/prompt state holds cleanly.

## Reuse Value

Useful for searchDemo, prompt-composer scenes, AI command entry, toolbar-driven request flows, and product typing interactions.

## Risks

- Input copy can overflow very quickly.
- Too many inline tools reduce readability.
- Motion has to feel like product input, not a decorative bar.
