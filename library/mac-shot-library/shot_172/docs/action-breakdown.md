1. workspaceFrameLift: establish the product shell and headline.
2. genreTabTraverse: move the active selection rail through category rows.
3. previewCanvasSwap: crossfade and slide preview states inside one reserved canvas.
4. detailCardResolve: update the compact context card with the selected genre.
5. workspaceHold: settle the final state for review.
