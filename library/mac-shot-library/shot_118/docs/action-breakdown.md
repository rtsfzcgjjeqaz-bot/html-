## Visual Structure

A dark productivity workspace fills the frame at a slight angle. A purple task card returns from the workflow rail and pins itself into a focused inbox or schedule board. A quick-step toolbar and side navigation make the surface read as an app grid, not a decorative card stack.

## Motion Structure

1. commandBoardPush: dark app board pushes into view.
2. quickStepToolbarSweep: top toolbar icons sweep on.
3. floatingTaskReturn: purple task card returns from the prior fanout.
4. inboxRowFocus: focused row highlights in the message list.
5. pinConfirmPulse: blue pin/cursor confirms the task is attached.
6. appGridSettle: board settles into a reusable appGrid composition.

## Reuse Value

Reusable for agent inbox, command center, email-to-task, schedule board, and productivity dashboard showcase shots.

## Risks

Avoid overloading the dark board with too much copy. The floating task card must clearly attach to a row or target area. Toolbar icons should remain compact and semantic.
